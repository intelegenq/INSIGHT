# Insight web

## Competition preview

The UI works in `demo` mode and does not require an API key or paid service.

### Deploy on Vercel

1. Import `qwertyIQ/Insight` as a new Vercel project.
2. Set **Root Directory** to `apps/web`.
3. Keep the detected package manager as **pnpm**.
4. Deploy.

No environment variables are required for the initial preview. The dashboard intentionally labels its signals as illustrative until collectors and evidence sources are connected.
